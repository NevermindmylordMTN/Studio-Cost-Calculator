# Studio-Cost-Calculator
Studio Cost Calculator

Project 001 | Python | Beginner Programming Project

About the Project

After completing Course 1 of the Programming for Everybody (Getting Started with Python) course by Dr. Charles Severance (Dr. Chuck), I decided to put the knowledge I had gained into practice by developing a project of my own.

Rather than simply moving on to the next course, I wanted to challenge myself to build something practical that would require me to apply the Python fundamentals I had just learned.

Coming from a fashion development background, I decided to create a Studio Cost Calculator: a simple command-line application designed to calculate the development costs of a garment.

The project gave me an opportunity to take a real-world process from the fashion industry and translate it into a basic programming solution.

What Does It Do?

The Studio Cost Calculator allows a user to generate a basic garment development cost estimate by entering:

Client name

Garment name

Fabric quantity required (metres)

Fabric price per metre

Labour hours

Labour cost per hour

Additional material costs

The application then calculates the individual costs and combines them to produce a total development cost.

It also categorises the quotation into one of three development cost levels:

Low Cost Development: Below R500

Medium Cost Development: R500–R1,500

High Cost Development: Above R1,500

Once a quotation has been generated, the user can choose whether they would like to calculate another garment.

Python Concepts Applied

One of my main objectives was to use as many of the fundamental concepts covered in Course 1 as possible.

The project allowed me to practise the following:

1. Variables and Data Types

Used variables to store information collected from the user, including client details, garment information and costing inputs.

2. User Input

Used input() to collect information and make the application interactive.

3. Type Conversion

Used float() to convert numerical inputs into decimal values. This was particularly important for monetary values, where cents need to be accounted for.

4. Arithmetic Operations

Applied multiplication and addition to calculate fabric costs, labour costs and the final development cost.

5. Conditional Statements

Used if, elif and else statements to categorise the final development cost based on predefined price ranges.

6. Functions

Created reusable functions for calculating fabric and labour costs. This allowed me to separate calculations into smaller sections rather than repeating the same formulas throughout the program.

7. While Loops

Used while loops to allow the application to repeat certain processes, including validating user input and generating multiple quotations.

8. Break and Continue Statements

Used break to exit loops and continue to restart an iteration when necessary.

9. Error Handling

Applied basic error handling to prevent invalid numerical inputs from interrupting the program.

Understanding how function parameters work and how values are passed into functions.

Correctly converting user input into numerical data types.

Understanding the difference between if statements and while loops.
